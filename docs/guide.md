# LyricoX 使用指南

> 本指南对应 LyricoX（本地音乐标签 / 歌词 / 封面编辑工具）的功能与操作习惯。
> 如有出入，以应用内实际界面为准。欢迎在仓库 Issues 反馈问题。

## 1. 安装与更新

- 仅提供 **arm64-v8a（64 位）** 安装包；安装前需在系统设置中允许「未知来源」安装。
- 各版本证书一致、versionCode 递增，**直接覆盖安装**即可，不会丢失曲库与已写入的标签。
- 与官方 Lyrico 同包名但签名不同：装过官方版会提示签名冲突，需先卸载官方版。
- 应用内更新：国内网络**优先从 Gitee 检查与下载**，Gitee 不可用时自动回落 GitHub。
  也可直接到 Releases 页面手动下载（Gitee / GitHub 内容一致）。

## 2. 曲库来源与扫描

1. **授权文件夹**：设置 → 文件夹管理 → 添加手机里的音乐文件夹（SAF 授权）。
2. **扫描整个媒体库**（设置内开关）：开启后直接读取系统媒体库索引，
   `/Download` 等无法 SAF 授权的位置也能扫到；两路扫描结果会自动去重合并。
3. 手动重新扫描：「曲目 / 专辑 / 艺术家」页右上角刷新按钮，或下拉刷新。
4. 曲库索引在本地数据库，扫描过一次的内容重启不丢；改动文件后刷新对应页面即可。

## 3. 编辑标签 / 歌词 / 封面

- **单曲编辑**：曲目列表进入歌曲 → 编辑页。支持 MP3 / FLAC / M4A / WAV / OGG / APE 等格式，
  WMA 仅支持读取（只读）。
- **在线匹配**：搜索多个在线源（含国内源）自动补全标签 / 歌词 / 封面；
  结果**先预览再写入**，逐字段勾选，低置信度结果会有标注。
- **批量任务**：可对整库、专辑、搜索结果多选批量执行；任务进度在任务中心查看。
- **写入撤销**：批量写标签/歌词会记录旧值，任务列表里可对整批或单条**回滚**（封面除外）。

## 4. 实用工具（设置 → 其他）

三个工具都遵循同一模式：**自动扫描 → 列出计划 → 勾选确认 → 执行**，确认前不动任何文件。

### 4.1 重复文件检测（查重）

- 按文件名相似度分组找出疑似重复；每组标注一个「建议保留」（无复制痕迹 > 体积更大 > 路径更短），
  其余默认勾选删除，可手动增删。
- 归一规则能识别 `(1)`、`- 副本`、`copy` 等复制痕迹；**短文件名（4 字以内）一字之差不判重**，避免误删。
- 建议先做「文件名清理」再查重，命中率更高。

### 4.2 文件名清理

- 批量去除文件名里的音轨前缀（`01 -` / `01.`）、首尾 `[ ]` / `《 》` 括号、结尾数字尾巴和多余空格。
- 每条显示「新名 + 旧名」，确认后逐个重命名；目标目录已有同名文件时跳过不覆盖。

### 4.3 目录整理

- 按「**艺人 / 专辑**」把授权文件夹里的歌曲归位；缺艺人标签的歌会先从文件名反解（`艺人 - 歌名` 双向）。
- 移动方式为「完整复制 → 校验字节数 → 删除源文件」，任何失败都会回滚，不会留下重复文件。
- 目前仅处理**文件夹授权（SAF）**来源的歌曲；来自系统媒体库索引的歌会保留原位并提示数量。
- 整理前建议开启「扫描整个媒体库」，这样移动后的歌曲无论落在哪个目录都能被扫到。

## 5. 常见问题

- **提示签名冲突**：装过官方 Lyrico，先卸载官方版再安装本应用。
- **写入失败要求授权**：系统会弹出 SAF 授权框，按提示放行该文件夹即可。
- **歌词写入格式**：支持向标签写入 LRC 内容；歌词顺序/翻译轨可在编辑页调整。
- **ReplayGain**：支持对整库或所选歌曲计算并写入回放增益信息。
- **隐私**：应用不收集任何数据；联网仅用于在线匹配与检查更新。
